# Upstream

This repository is a public fork of
[`comfyanonymous/ComfyUI`](https://github.com/comfyanonymous/ComfyUI) (GPL-3.0), kept in the
GitHub fork network with full lineage. Upstream owns the product: engine, nodes, frontend,
and documentation ([docs.comfy.org](https://docs.comfy.org/)). ForgeGuard owns the hardening
delta documented in [forgeguard-changes](./forgeguard-changes.md) and the
[ComfyUI-Foundry](https://github.com/forgeguard-ai/comfyui-foundry) distribution built from it.

This project is not affiliated with or endorsed by Comfy Org.
