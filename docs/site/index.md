# ForgeGuard ComfyUI fork

This site documents only the **ForgeGuard delta**: what this fork removes, adds, and
guarantees relative to [upstream ComfyUI](https://github.com/comfyanonymous/ComfyUI). For how
ComfyUI itself works, use the [upstream documentation](https://docs.comfy.org/).

- [ForgeGuard changes](./fork/forgeguard-changes.md) — the authoritative list of every delta.
- [Compatibility](./fork/compatibility.md) — upstream tracking policy and behavior notes.
- [Upstream](./fork/upstream.md) — lineage and links.

The prebuilt, production-oriented distribution of this fork is
[ComfyUI-Foundry](https://github.com/forgeguard-ai/comfyui-foundry).
